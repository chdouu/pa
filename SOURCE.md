# Upstream source

The `pa_agent/` analysis core and `prompt_engineering/` strategy library were copied
from the adjacent PA_Agent working tree on 2026-09-19.

- Git commit at copy time: `1accb3d49f05be51e7800f60cfe0cbc4dfb90a5d` (`1.37`)
- The upstream working tree contained local, uncommitted changes. PA Server captures
  the files as they existed on disk at copy time.
- Runtime configuration, API keys, records, logs, virtual environments and GUI code
  were deliberately excluded.
